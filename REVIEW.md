# Проверка Explorer — 6 ноября 2026

Проверены файловые сервисы, состояние навигации и выделения, AppKit-мосты,
команды активного окна, главное меню, контекстные меню списка и значков.
Ниже перечислены внесённые исправления и результаты проверки.

## Исправления

- Архивирование: буквальная обработка имён, безопасная работа с символическими
  ссылками, отсутствие блокировки на выводе процесса, очистка временных файлов,
  публикация архива без перезаписи существующего.
- Файловые операции: защита от копирования каталога в себя и потомков, включая
  пути через ссылки; ограничения длины имени; сообщение о частичном копировании.
- Корзина: сохранение успешно удалённых элементов для Undo при частичной ошибке;
  восстановление исходных имён без перезаписи занятого пути.
- Обновление каталога: отслеживание изменений файлов и замены самого каталога;
  защита от устаревших результатов загрузки и операций после навигации.
- Чтение файловой системы: медленный системный вызов одного каталога больше
  не блокирует проверки других путей и очередь записи. Уже зависший вызов
  macOS при этом может продолжать ждать.
- Выделение и переименование: сохранение выделения после rename без перехвата
  нового выбора пользователя; стабильная идентичность строк; редактор имени
  в сетке получает фокус, корректно обрабатывает Enter, Escape и потерю фокуса.
- Меню и клавиатура: команды направляются в активное окно; текстовые Cut/Copy/
  Paste/Select All/Undo/Redo обслуживает текстовый редактор; исправлены доступность
  команд, удаление нескольких выбранных объектов из контекстного меню и стрелки сетки.
- Адрес и фильтр: Tab завершает актуальный путь; ошибочный адрес остаётся доступным
  для исправления; устаревшая проверка не меняет новый каталог; Escape закрывает фильтр.
- Представление: обновление метаданных и состояния Cut в строках, согласование
  сортировки, видимость колонок, цветные теги Finder, подписи скрытых кнопок панели.
- Боковая панель: сохранение пустого списка избранного и повторная проверка доступности.
- Drag and drop: согласование операции копирования/переноса, текущий каталог как
  назначение для пустого списка, проверка провайдеров только на допустимом этапе
  SwiftUI, сообщения об ошибках передачи файла. Значки SwiftUI предлагают
  копирование; источник из native-списка может предлагать перенос.
- Get Info показывает сведения о файле; ошибки Open/Open With/Terminal выводятся
  в соответствующем окне.

## Подтверждённые проверки

Итоговая сборка успешна. **54 теста в 11 наборах прошли.** `git diff --check`
не обнаружил ошибок. Команда запуска тестов с установленным SDK описана в README.

В отдельной тестовой сборке и на временных файлах проверены:

- New Folder, Go to Folder, Back/Up, открытие папки, ошибочный адрес и Tab completion;
- Copy/Paste, Cut/Paste, Duplicate, Compress с проверкой содержимого файлов/ZIP;
- переименование в списке и сетке, сохранение выделения, отмена Escape, стрелки;
- Get Info, теги, Open With через TextEdit;
- фильтр с совпадениями и без них, Escape, показ скрытых файлов;
- вкладки и действие команды только в активной вкладке;
- добавление и удаление избранного, скрытие и восстановление колонки Tags;
- удаление двух тестовых файлов в Корзину и Undo в списке и сетке.
  Оба файла восстановлены под исходными именами с исходным содержимым;
- переход в тестовый каталог, пока чтение домашней папки ожидает метаданных macOS;
- перетаскивание beta.txt на Folder A: ручной жест подтверждён пользователем,
  обработчик выполнил копирование в нужную папку. Проверка на диске подтвердила
  сохранность исходного файла и побайтовое совпадение копии.

## Границы проверки

- Автоматический жест перетаскивания не завершает drop в этом окружении;
  соответствующий сценарий проверен ручным жестом пользователя и проверкой файлов.
- Проверка окна Terminal заблокирована инструментом управления интерфейсом;
  правильный рабочий каталог Terminal не подтверждён кликами.
- Не запускались все установленные приложения из Open With и все системные
  пункты меню macOS. Прохождение тестов не доказывает отсутствие любых багов.
- Во время ручной проверки Copy/Paste вспомогательный скрипт не восстановил
  прежнее содержимое общего буфера обмена из-за несовпадения /var и /private/var.
  Пользователь уведомлён; прежнее содержимое восстановить не удалось.
